# Körpasset brand assets

Låst riktning: **Länken / Vägbanor**

Tagline: **ÖVNING IDAG. FRIHET IMORGON.**

## Färger
- Deep Navy: `#1A2B4C`
- Teal: `#00C896`
- Off-white: `#F8F9FA`

## Filer
- `korpasset-logo.svg` – horisontell wordmark för webbheader
- `korpasset-logo-tagline.svg` – logotyp + tagline
- `korpasset-symbol.svg` – symbol utan text
- `favicon.svg` – favicon
- `korpasset-og-1200x630.png` – Open Graph / social preview (1200×630)
- `korpasset-social-1024.png` – Facebook/Instagram profilbild, ljus
- `korpasset-social-dark-1024.png` – Facebook/Instagram profilbild, mörk
- `korpasset-logo-1200.png` – PNG-preview/bruk där SVG inte stöds
- `korpasset-logo-tagline-1600.png` – PNG med tagline

## Rekommenderad användning
- Webbheader: `korpasset-logo.svg` (symbol + wordmark, ingen tagline)
- Favicon: `favicon.svg` (symbol utan text)
- Open Graph: `korpasset-og-1200x630.png`
- Facebook / Instagram profilbild: `korpasset-social-1024.png`
- Alternativ mörk profilbild: `korpasset-social-dark-1024.png`

Profilbilderna är till för sociala kanaler och ska inte renderas i webbheadern.
